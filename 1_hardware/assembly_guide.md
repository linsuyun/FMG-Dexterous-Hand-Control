## 三层柔性结构设计

### 层级概述

```
┌─────────────────────────────────────┐

│  厚度：1-2mm                        │

└─────────────────────────────────────┘
              ↓
┌─────────────────────────────────────┐
│  第一层：PCB电路板层                 │
│  材料：柔性PCB或标准PCB             │

│  接口：SPI/I2C 传感器接口            │
│         USB/蓝牙 数据输出             │
└─────────────────────────────────────┘
```

## 组装步骤

### 步骤 1: PCB 焊接与组装

1. **准备 PCB**
   - 使用柔性 PCB 或标准 PCB（厚度 0.2-1.6mm）
   - 清洁 PCB 表面，去除油污

2. **焊接微控制器**
   ```
   STM32L476RG 引脚焊接：
   - VDD (电源): 3.3V
   - GND (接地): GND
   - SWDIO/SWCLK: 程序下载接口
   ```

3. **焊接电源电路**
   - AMS1117-3.3V 稳压器
   - 输入端：5V USB 电压
   - 输出端：3.3V 给传感器和微控制器

4. **焊接通信接口**
   - USB 接口或 CH340G 转串口模块
   - HC-05 蓝牙模块（可选）

### 步骤 2: 磁传感器集成

1. **传感器排列设计**
   ```
   4 行 × 6 列矩阵排列
   
   手臂周长: ~30cm
   传感器间距: ~5cm (环向) × 5cm (纵向)
   
   排列方案:
   Row 1: 传感器 1-6
   Row 2: 传感器 7-12
   Row 3: 传感器 13-18
   Row 4: 传感器 19-24
   ```

2. **MLX90393 传感器焊接**
   ```
   引脚连接 (I2C 模式):
   VDD   → 3.3V
   GND   → GND
   SDA   → STM32 PB11 (I2C2_SDA)
   SCL   → STM32 PB10 (I2C2_SCL)
   ```

3. **I2C 地址配置**
   - 使用地址跳线为每个传感器分配不同的 I2C 地址
   - 地址范围: 0x0C - 0x0F (通过硬件跳线配置)

### 步骤 3: 柔性皮肤制造

1. **模具制作**
   ```
   使用 3D 打印或传统模具：
   - 外形：圆形护臂形状
   - 内部凹陷：24 个传感器位置
   - 厚度：1-2mm
   ```

2. **硅胶浇铸**
   ```
   材料：医用级硅胶
   
   步骤：
   a) 将硅胶原液和固化剂按 10:1 混合
   b) 真空脱泡 10-15 分钟
   c) 倒入模具，放置 PCB 和传感器
   d) 室温固化 24 小时
   e) 脱模并固化处理
   ```

3. **表面处理**
   - 打磨表面，去除毛刺
   - 可选：添加织物或凹槽增加摩擦力

### 步骤 4: 传感器安装

1. **固定磁传感器**
   ```
   使用导电胶固定每个传感器到 PCB：
   - 清洁粘贴面
   - 涂抹导电胶（3M 或相同品牌）
   - 对齐传感器位置
   - 固化 2-4 小时
   ```

2. **验证连接**
   ```
   使用万用表测量：
   - 检查 I2C 总线连接
   - 验证每个传感器的电源线
   - 测试数据线完整性
   ```

### 步骤 5: 绑带集成

1. **绑带设计**
   ```
   基底材料：弹性天鹅绒布
   - 宽度：10-15cm
   - 长度：30-35cm（适配不同手臂周长）
   
   绑带结构：
   ┌─────────────────────┐
   │   皮肤层 + 传感层    │  ← 面向皮肤
   ├─────────────────────┤
   │    PCB 电路板        │  ← 数据处理
   ├─────────────────────┤
   │    绑带基底          │  ← 支撑结构
   └─────────────────────┘
   ```

2. **魔术贴安装**
   - 在绑带两端粘贴魔术贴（粗面和毛面各一面）
   - 这允许可调节的佩戴松紧度

3. **缝制加强**
   ```
   使用医用级缝线缝制结构完整性：
   - 缝制绑带边缘
   - 固定 PCB 到绑带
   - 加强接触点
   ```

## 测试与验证

### 功能测试

1. **电源测试**
   ```bash
   # 使用万用表测量
   - VDD 应为 3.3V ±5%
   - GND 应为 0V
   - 无短路（>10MΩ)
   ```

2. **通信测试**
   ```bash
   # 使用 I2C 扫描工具
   python i2c_scanner.py
   # 应检测到 24 个传感器地址
   ```

3. **数据采集测试**
   ```bash
   # 运行数据采集脚本
   python collect_sensor_data.py
   # 验证每个通道都有有效数据
   ```

### 性能验证

1. **采样率**
   - 目标: 1000 Hz
   - 允许范围: 900-1100 Hz

2. **信噪比 (SNR)**
   - 目标: > 20 dB
   - 测量: 信号 RMS / 噪声 RMS

3. **延迟**
   - 采集延迟: < 5 ms
   - 传输延迟: < 20 ms (USB) 或 < 100 ms (蓝牙)

## 故障排除

### 常见问题

| 问题 | 可能原因 | 解决方案 |
|------|--------|--------|
| 无法检测传感器 | I2C 总线故障 | 检查 SCL/SDA 连接，测试下拉电阻 |
| 传感器数据异常 | 焊接不良或接触不良 | 重新焊接传感器，清洁接触点 |
| 采样率���稳定 | USB 干扰或电源不足 | 使用屏蔽线，检查电源容量 |
| 信号噪声大 | EMI 干扰 | 添加滤波电容，缩短走线长度 |
